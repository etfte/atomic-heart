# 🏆 Atomic Heart Achievements Tracker // Facility 3826

A comprehensive, fully interactive achievements, collectibles, and secrets tracker for **Atomic Heart** and all 4 DLCs:
- **Base Game** (Facility 3826)
- **DLC 1: Annihilation Instinct** (Mendeleev Complex)
- **DLC 2: Trapped in Limbo** (Limbo Realm)
- **DLC 3: Enchantment of the Deep Seas** (Neptune Deep Sea Sector)
- **DLC 4: Crystal Dawn** (Crystal Facility & Citadel)

---

## ⚡ Key Features

- **82 Achievements Complete Database**:
  - Detailed conditions, locations, missable warnings (⚠️), and chronological stage route sorting.
  - One-click YouTube video guides with exact timestamps and YouTube search integration.
- **Steam Automatic Synchronization**:
  - Live Steam profile integration via 17-digit SteamID (`76561199...`) or custom profile URL.
  - Automatic progress bar, play time, remaining hours calculator, and rarity tiers (Common, Uncommon, Rare, Legendary).
- **🗺️ Interactive Tactical Map (5 Realms)**:
  - Facility 3826, Mendeleev Complex, Limbo, Neptune, and Crystal Facility.
  - Zero-jitter interactive pins, testing polygons 1–12, and points of no return.
- **🔐 Lock & Code Solver (16 Combinations)**:
  - Visual diagram schemes with illuminated bulb dials.
  - ⚡ **Interactive Laser Relay Puzzle Simulator**: realistic optical ray tracing, rotatable optical prism discs (90° physics deflection), and instant auto-solve solver.
- **🦝 Dedicated DLC Secrets Tracker**:
  - 11 RACON Figurines (DLC 4), 3 Hunter Caches & Moby Dick chirper (DLC 3), Limbo Apples & 76 Coins (DLC 2), 8 BEA-D spheres (DLC 1).
  - Integrated checkbox cards matching main achievements style with localStorage persistence.
- **🤖 HRAZ Enemy Scanner & 🛠️ ELEONORA Arsenal**:
  - Boss vulnerabilities, elemental resistances, weapon crafting blueprints, and upgrade materials calculator for the *More Than Human / Lord of War* trophies.

---

## 🚀 Quick Start

1. **Web Version**: Simply open `index.html` or `Atomic Heart Achievements.html` in any modern web browser.
2. **Local Steam Sync Server**:
   ```bash
   python sync_server.py
   ```
   Or run the compiled executable from the launcher folder.
